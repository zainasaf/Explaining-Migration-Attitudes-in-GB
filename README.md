This repository contains the R code behind Explaining Migration Attitudes, a presentation prepared for More in Common in June 2025 that examines what shapes British public opinion on immigrant and refugee numbers. Using a nationally representative survey that includes More in Common's seven-segment typology, Immigration_data_visualizations.Rmd produces the descriptive analysis: how attitudes to immigrants and refugees compare, how salient migration is relative to other issues, and which demographic and political groups are most opposed to current levels. Immigration_Models.Rmd then fits multinomial logit models of segment membership and ordered logit models of immigration preferences, using average predicted probabilities and pairwise comparisons from marginaleffects to test how drivers interact, including education by urban–rural location, gender by age, financial security by left–right vote, and housing affordability by age. The headline finding is a strong asymmetry in attitudes: people who rank migration as a priority overwhelmingly want lower numbers, while support for higher numbers is largely confined to those for whom it is a low-salience issue. The models also suggest that place type matters more than education, and that financial insecurity shifts the immigration preferences of right-leaning voters but not those on the left.
